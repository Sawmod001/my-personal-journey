# Internet Fundamentals - Review Questions

## 1. What is the Internet?
The Internet is a global network of interconnected computers and devices that communicate and share information using standard protocols.

## 2. Explain the difference between the Internet and the World Wide Web.
The Internet is the infrastructure that connects computers worldwide, while the World Wide Web (WWW) is a service that uses the Internet to access websites and web pages.

## 3. What is the role of an ISP?
An Internet Service Provider (ISP) supplies users with access to the Internet and related services such as email, web hosting, and technical support.

## 4. What is an IP address?
An IP (Internet Protocol) address is a unique numerical identifier assigned to a device on a network, allowing it to send and receive data.

## 5. What does DNS do?
The Domain Name System (DNS) translates human-readable domain names (such as google.com) into IP addresses that computers can understand.

## 6. Explain the difference between HTTP and HTTPS.
HTTP (HyperText Transfer Protocol) is used for transferring web data, while HTTPS is the secure version of HTTP that encrypts communication using SSL/TLS.

## 7. Mention three benefits of the Internet.
- Fast communication through email, messaging, and video calls.
- Access to educational resources and information.
- Online business, banking, and e-commerce opportunities.

## 8. List three Internet security best practices.
- Use strong and unique passwords.
- Enable Two-Factor Authentication (2FA).
- Avoid clicking suspicious links or downloading files from unknown sources.
